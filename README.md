# 斩页 Web Slasher🗡️

> 觉得上班无聊？😊
>
> 又或者，看不惯网上的某些地方？👿
>
> 那就进入斩击模式，把它们一页一页砍掉吧！⚔️

一款无需构建步骤的 Chrome Manifest V3 扩展。进入斩击模式后，鼠标会变成剑，左键负责“说服”网页元素暂时消失；元素越大，越难砍，击破分数也越高。

放心，这不是一键拆站。元素只是被临时藏起来，退出模式、刷新页面或换网址后就会恢复。
大部分代码由deepseek-v4-falsh与codex合作生成

## 一分钟上手

1. 安装扩展。
2. 打开一个普通网页。
3. 按 `Alt+Shift+S` 进入斩击模式。
4. 移动鼠标，左键点击想砍的元素。
5. 砍累了就单击右键退出，或者再按一次快捷键。
6. 点击浏览器工具栏里的扩展图标，查看分数、切换剑和音效。

如果只想先体验，上面这六步已经够用了。下面是给认真玩家准备的普通用户手册。

## 安装

目前可以直接从源码安装，不需要 `npm install`，也不需要打包：

1. 下载或克隆仓库，确保本机有一个包含 `manifest.json` 的项目文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的项目根目录。
6. 建议把“斩页”固定到工具栏，之后查看分数和切换设置会方便很多。

如果以后从 Chrome 网上应用店安装，则可以直接点击“添加到 Chrome”，然后跳过开发者模式。

## 普通用户手册

### 1. 进入斩击模式

默认快捷键是 `Alt+Shift+S`。

进入后：

- 鼠标会变成剑形光标。
- 页面会出现分数和连击状态。
- 左键用于斩击，不再负责网页原本的点击操作。
- 右键不会打开网页菜单，而是退出斩击模式。

也可以点击扩展图标，在弹窗中按“进入模式”或“退出模式”。弹窗里的按钮对当前活动标签页生效。

### 2. 怎么斩

- 把剑移到目标附近，单击左键。
- 剑光角度会跟随最近约 100ms 的鼠标移动方向，所以动作快一点会更像在挥剑。
- 小型元素通常一刀结束。
- 大型元素需要连续攻击，最多五刀，但每次有效命中都会掉分。
- 大约 1.5 秒内连续命中会积累连击倍率，最高 `x3.50`。
- 在斩击模式里，左键不会触发链接、按钮或输入框原本的点击行为。

简单说，先瞄准，再出剑，不要试图用一次点击解决整家公司。

### 3. 退出与恢复

以下操作都会结束本次斩击：

- 在斩击模式内单击右键。
- 再按一次当前切换快捷键。
- 在扩展弹窗中点击“退出模式”。
- 刷新页面或跳转到新网址。

被砍掉的元素是临时隐藏的，退出斩击模式后就会回来。扩展不会修改网页服务器上的内容，也不会把元素永久删除。

### 4. 自定义快捷键

1. 点击扩展图标。
2. 进入快捷键设置。
3. 点击快捷键录制按钮。
4. 按下你想使用的组合键。

组合键必须包含至少一个修饰键和一个主键，例如 `Ctrl+Shift+X`。这样能尽量避免和网页输入、浏览器快捷键互相打架。设置页也可以恢复默认的 `Alt+Shift+S`。

### 5. 弹窗里有什么

点击扩展图标后，可以查看：

- 当前页面的本页得分。
- 历史总分。
- 连续命中形成的连击倍率。
- 已解锁和下一把待解锁的剑。
- 当前选中的剑。
- 音效开关。
- 进入或退出斩击模式的按钮。
- 自定义快捷键入口。

## 计分规则

元素刚露出来的可见面积越大，耐久越高，基础分也越高：

| 可见面积 | 耐久 | 基础分 |
| --- | ---: | ---: |
| `<= 4,000 px²` | 1 | 15 |
| `<= 16,000 px²` | 2 | 40 |
| `<= 64,000 px²` | 3 | 90 |
| `<= 256,000 px²` | 4 | 200 |
| `> 256,000 px²` | 5 | 450 |

规则很简单：

- 每次有效命中造成 1 点耐久伤害。
- 击破目标会额外获得基础分的 25%。
- 约 1.5 秒内连续命中会提高连击倍率。
- 本页得分只属于当前页面。刷新、离开或换网址后，本页得分会重新开始。
- 历史总分会被累计保存，用来解锁剑。

所以，大元素虽然难砍，但砍穿以后更值钱。这也算给耐心的一点尊重。💸

## 剑库与解锁

| 剑 | 历史总分 |
| --- | ---: |
| 铁刃 | 0 |
| 雷光 | 1,000 |
| 霜锋 | 4,000 |
| 赤霄 | 16,000 |
| 星陨 | 64,000 |
| 无相 | 256,000 |

从雷光开始，每把剑的解锁分数都是上一把的 4 倍。历史总分可以跨页面累计；在同一个网页反复刷分，也会计入历史总分并解锁剑。

所有剑都是纯视觉效果，不会偷偷改变伤害、分数或爆率。没有隐藏的终极剑气，只有更好看的挥剑人生。✨

## 能砍什么

扩展主要面向普通 `http`、`https` 和本地开发页面，并尽可能筛选页面上的可见元素。

通常可以斩击：

- 网页里的图片、按钮、标题、卡片和广告区域。
- 普通页面中的可见容器和内容元素。
- 本地开发页面中的界面元素。

无法运行或会被安全跳过的页面包括：

- Chrome 内置页，例如 `chrome://` 开头的页面。
- Chrome 网上应用店。
- 浏览器禁止内容脚本注入的其他页面。
- 复杂内嵌框架或没有可攻击可见元素的页面。

扩展在这些页面上会安静跳过，不会追着浏览器本体砍。浏览器暂时还不归你管。🚧

## 常见问题

### 按快捷键没有反应

确认当前标签页是普通网页，并检查快捷键是否和浏览器或系统快捷键冲突。可以到快捷键设置页换一个组合键。

### 鼠标没有变成剑

先确认已经进入斩击模式。如果是 Chrome 内置页、网上应用店或受限页面，扩展无法注入，因此不会显示剑和状态栏。

### 为什么小图标一刀就没了，大区域要砍好几刀

因为分数得讲一点基本法。大元素掉分高，耐久也高，这样一刀秒掉整个页面就没那么无聊了。

### 退出后元素会回来吗

会。退出模式、刷新或换网址后，扩展会恢复被它临时覆盖的样式。页面本身没有被永久修改。

### 刷新后本页得分去哪了

本页得分只存在当前页面内存里，刷新后重新开始。历史总分保存在扩展本地存储中，用来解锁剑。

### 怎样换剑

点击扩展图标，在剑库中选择已经解锁的剑。未解锁的剑会显示所需历史总分。

### 音效怎么关

点击扩展图标，然后切换“音效开启/音效关闭”。

### 会不会上传我的浏览记录

当前版本不会。第一阶段没有账号、排行榜、联网请求或服务端。

## 隐私与本地数据

- 本页得分只保存在页面内存中。
- 历史总分、已选剑和音效偏好保存在浏览器本地存储中。
- 当前版本不要求注册、登录或提交个人信息。
- 当前版本不会把浏览记录或分数上传到服务器。
- 当前版本不包含排行榜功能。

## 开发与测试

纯逻辑测试使用 Node.js 内置测试运行器：

```bash
npm test
```

如果本机安装了 Chrome，可以运行自动浏览器冒烟测试：

```bash
npm run smoke
```

主要文件：

- `src/core.js`：面积分级、耐久、得分、连击、剑解锁和组合键逻辑。
- `src/dom.js`：可见面积、元素筛选和剑刃采样。
- `src/content.js`：模式生命周期、命中、渲染、恢复和存储同步。
- `src/overlay.css`：Shadow DOM 内的 HUD、状态栏样式。
- `popup/`：分数、模式、剑库和音效控制。
- `options/`：切换组合键录制。

手动验收步骤见 `test/manual/checklist.md`，完整说明见 `docs/manual-testing.md`。

设计稿位于 `docs/superpowers/specs/2026-10-02-slice-web-elements-extension-design.md`。
