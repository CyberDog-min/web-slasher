# 斩页 Page Slash

一个无需构建步骤的 Chrome Manifest V3 扩展。进入斩击模式后，鼠标会变成剑形光标，点击可以斩击网页元素并获得分数；元素越大，耐久越高，击破奖励也越高。

## 功能

- 默认使用 `Alt+Shift+S` 进入或退出模式。
- 模式内左键出剑，右键退出并恢复页面。
- 剑光角度跟随最近约 100ms 的鼠标移动方向。
- 小型元素一击击破，大型元素最多需要五次攻击。
- 连续命中会累积连击倍率，最高 `x3.50`。
- 被击破的元素会暂时隐藏，退出模式、刷新或 URL 改变后恢复。
- 本页得分只保存在内存中，历史总分保存在 `chrome.storage.local`。
- 历史总分解锁六把纯视觉剑；剑不会改变伤害或分数。
- 支持音效开关、自定义组合键和减少动态效果偏好。
- 第一阶段不包含账号、排行榜、联网请求或服务端。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择这个仓库的根目录。

扩展不需要 `npm install`，也不需要打包步骤。

## 使用

- 在普通网页按 `Alt+Shift+S` 进入斩击模式。
- 单击鼠标左键斩击指针附近或者最近移动轨迹经过的元素。
- 在模式内单击右键退出。
- 点击扩展图标查看本页得分、历史总分、剑库和音效状态。
- 在“快捷键设置”页录制新的切换组合键。

组合键必须包含至少一个修饰键和一个主键，避免干扰普通输入。

## 计分规则

| 可见面积 | 耐久 | 基础分 |
| --- | ---: | ---: |
| `<= 4,000 px²` | 1 | 60 |
| `<= 16,000 px²` | 2 | 160 |
| `<= 64,000 px²` | 3 | 360 |
| `<= 256,000 px²` | 4 | 760 |
| `> 256,000 px²` | 5 | 1,600 |

每次有效命中造成 1 点耐久伤害。击破目标会额外获得基础分的 25%。约 1.5 秒内连续命中会提高连击倍率。

## 剑解锁

| 剑 | 历史总分 |
| --- | ---: |
| 铁刃 | 0 |
| 雷光 | 800 |
| 霜锋 | 2,500 |
| 赤霄 | 6,000 |
| 星陨 | 12,000 |
| 无相 | 22,000 |

## 支持范围

扩展面向普通 `http`、`https` 和本地开发页面。Chrome 内置页、Chrome 网上应用店以及浏览器禁止内容脚本注入的页面无法运行；扩展会安静跳过这些页面。

页面元素不会被持久删除。扩展只临时保存并覆盖目标元素的内联样式，退出模式后恢复。

## 开发

纯逻辑测试使用 Node.js 内置测试运行器：

```bash
npm test
```

如果本机安装了 Chrome，可以运行自动浏览器冒烟测试：

```bash
npm run smoke
```

主要文件：

- `src/core.js`：面积分级、耐久、得分、连击、剑解锁和组合键逻辑。
- `src/dom.js`：可见面积、元素筛选和剑刃采样。
- `src/content.js`：模式生命周期、命中、渲染、恢复和存储同步。
- `src/overlay.css`：Shadow DOM 内的 HUD、状态栏样式。
- `popup/`：分数、模式、剑库和音效控制。
- `options/`：切换组合键录制。

手动验收步骤见 `test/manual/checklist.md`，完整说明见 `docs/manual-testing.md`。

设计稿位于 `docs/superpowers/specs/2026-10-02-slice-web-elements-extension-design.md`。
