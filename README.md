# 斩页 Page Slash

一个 Manifest V3 浏览器扩展：进入斩击模式后，鼠标变为剑刃，点击可斩击网页元素、累积连击并获得分数。大型元素需要更多次斩击，但击破后得分更高。

## 当前阶段

- 普通网页自动准备斩击能力。
- 支持自定义组合键进入模式。
- 在斩击模式内点击出剑，鼠标右键退出。
- 击破元素后暂时隐藏，退出模式或刷新页面恢复。
- 本页分数独立，历史总分用于逐步解锁不同剑。
- 第一阶段不包含账号、联网排行榜或服务端。

## 开发状态

需求与架构设计已经确认，设计稿位于：

`docs/superpowers/specs/2026-10-02-slice-web-elements-extension-design.md`

扩展实现将使用原生 Manifest V3、JavaScript、Canvas 和 Shadow DOM，不依赖构建工具。

## 本地测试

开发完成后，在 Chrome 中打开 `chrome://extensions`，启用“开发者模式”，选择“加载已解压的扩展程序”，并指向本目录。
