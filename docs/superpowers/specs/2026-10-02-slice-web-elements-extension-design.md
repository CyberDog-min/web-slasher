# 网页斩击扩展设计

日期：2026-10-02

状态：设计已逐项确认，等待用户审核落盘版本。

## 1. 目标

构建一个无需构建步骤、可直接在 Chrome 中加载的 Manifest V3 扩展。扩展在普通网页中提供斩击模式：鼠标变为剑刃，点击可斩击页面元素，大元素需要更多次攻击并产生更高得分，元素被击破后暂时消失。

第一阶段只提供本地游戏体验，不包含排行榜、账号、联网请求、社交或云端数据。计分与剑解锁进度保存在扩展本地存储中，后续可接入排行榜服务。

## 2. 非目标

- 第一阶段不实现全球排行榜、每日榜、名字提交或任何服务端。
- 不修改网页源码，不向页面持久写入破坏状态；刷新或退出模式后元素恢复。
- 不提供影响伤害、耐久或分数的付费或数值型剑。
- 不在 `chrome://`、Chrome 网上应用店及浏览器明确禁止注入的页面运行。
- 不尝试穿透跨域 iframe 的内部 DOM；iframe 可作为一个页面元素被斩击。

## 3. 用户体验

### 3.1 进入与退出

- 扩展安装后，普通网页自动准备好斩击能力。
- 用户在设置页录制组合键，默认 `Alt+Shift+S`。
- 组合键在网页获得焦点时触发；未进入模式时进入，已进入模式时退出。
- 进入模式后隐藏系统指针，在页面最上层显示自定义剑形光标、剑光拖尾、顶部状态和底部计分 HUD。
- 在斩击模式内单击鼠标右键退出。扩展会拦截本轮右键菜单，退出后立即恢复普通鼠标和网页操作。
- 模式关闭后移除全部界面、动画、事件监听和页面样式改动。

### 3.2 斩击操作

- 单击在光标位置出剑。
- 出剑角度由最近约 `100ms` 内的鼠标移动向量决定。
- 鼠标几乎静止时使用默认右下斜劈。
- 连续点击拥有约 `90ms` 冷却，冷却结束后可再次斩击。
- 一次剑刃轨迹可以命中多个元素；同一元素在一次斩击内只结算一次伤害。
- 点击动作被扩展拦截，不会触发命中元素上的链接、按钮或其他默认操作。

### 3.3 命中判定

- 根据剑刃轨迹生成若干个采样点，并调用 `document.elementsFromPoint()` 获取这些位置的元素。
- 过滤不可见、过小、扩展自身、`html`、`body`、`script`、`style`、`meta`、`link` 等非游戏目标。
- 同一位置的嵌套元素优先选择最深层且满足可绘制条件的目标。
- 目标可见面积按元素包围盒与视口交集计算。
- 换页后立即恢复本页被隐藏的元素并清空本页得分。

## 4. 计分与耐久

每个元素按可见面积获得一个 1 至 5 点耐久和对应的基础分：

| 可见面积 | 耐久 | 基础分 |
| --- | ---: | ---: |
| `<= 4,000 px²` | 1 | 60 |
| `<= 16,000 px²` | 2 | 160 |
| `<= 64,000 px²` | 3 | 360 |
| `<= 256,000 px²` | 4 | 760 |
| `> 256,000 px²` | 5 | 1,600 |

- 每次有效斩击造成 1 点耐久伤害，分数按基础分除以耐久结算。
- 击破目标时额外获得基础分的 25%。
- 约 `1.5s` 内连续命中增加连击数。
- 连击倍率从 `1.0` 开始，每次增加 `0.15`，最高 `3.5`。
- 本页得分只保存在内存中，刷新或换页清零。
- 每次获得分数都会累加到“历史总分”。
- 历史总分用于解锁剑，刷新同一页面持续刷分也会累加。

## 5. 元素消失与恢复

- 元素被击破后播放短暂缩淡动画，并生成独立碎屑和火花。
- 隐藏通过保存并覆盖元素原有内联样式实现，不修改网页文件。
- 退出模式、切换页面或恢复页面前，扩展恢复元素原始样式。
- 页面自身动态删除元素时，扩展安全忽略该恢复步骤，不抛错。

## 6. 剑库与解锁

第一阶段提供 6 把纯视觉剑：

| 剑 | 历史总分门槛 |
| --- | ---: |
| 铁刃 | 0 |
| 雷光 | 800 |
| 霜锋 | 2,500 |
| 赤霄 | 6,000 |
| 星陨 | 12,000 |
| 无相 | 22,000 |

每把剑拥有独立的光标轮廓、剑光颜色、火花颜色和合成音色。切换剑只改变视觉与听觉反馈，不影响伤害和得分。

## 7. 设置与本地存储

扩展弹窗展示：

- 当前模式状态。
- 本页得分和历史总分。
- 剑库与下一把剑的解锁进度。
- 音效开关。
- 组合键入口。

设置页展示：

- 组合键录制器。
- 恢复默认快捷键按钮。
- 键盘冲突提示。

本地存储字段：

- `lifetimeScore`：历史总分。
- `customCombo`：已录制的组合键。
- `selectedSword`：当前选中的剑。
- `soundEnabled`：音效状态。

存储写入采用短延迟批量更新，避免每次命中都单独写磁盘。存储不可用或数据损坏时使用安全默认值，不影响网页浏览。

## 8. 架构

采用原生 Manifest V3，不引入框架或构建工具。

```text
manifest.json
assets/
  icons/
src/
  core.js
  content.js
  overlay.css
popup/
  popup.html
  popup.css
  popup.js
options/
  options.html
  options.css
  options.js
test/
  core.test.js
  manual/
    fixture.html
```

职责边界：

- `src/core.js`：纯逻辑，不依赖 DOM 或 Chrome API；实现面积分级、耐久、得分、连击、剑解锁和组合键规范化。
- `src/content.js`：模式开关、命中检测、元素隐藏与恢复、URL 变化处理、存储同步。
- `src/overlay.css`：通过 Shadow DOM 隔离的 HUD、剑光标和动画样式。
- `popup/`：展示状态、分数、剑库和音效开关，读写本地设置。
- `options/`：录制并保存自定义组合键，恢复默认快捷键。
- `test/core.test.js`：使用 Node 内置测试运行器验证纯逻辑。

核心逻辑以同时兼容浏览器全局对象和 CommonJS 的方式导出，扩展运行时不需要额外打包。

## 9. 性能与兼容

- 使用单个 `requestAnimationFrame` 动画循环。
- 活跃粒子限制为约 240 个，超限时优先回收最旧粒子。
- 退出模式时清除全部定时器、监听器、Canvas、HUD 和临时样式。
- 页面动态加载的元素无需注册观察器，命中时即时读取。
- 页面 CSS 由 Shadow DOM 和扩展样式隔离。
- 遵循 `prefers-reduced-motion`，减少动画与粒子。
- 普通 `http`、`https` 和本地开发页面均在 `all_urls` 范围内。
- 浏览器内置页和商店页无法注入时静默跳过，不显示错误。

## 10. 安全与可靠性

- 第一阶段无联网权限，不收集页面内容、浏览历史或用户身份。
- 内容脚本只读写自身覆盖层、目标元素的临时内联样式和扩展存储。
- 恢复目标元素时使用进入游戏前保存的原值，避免覆盖网页后续改动。
- 组合键录制至少要求一个修饰键与一个主键，避免单键干扰正常输入。
- 页面存在异常样式、Trusted Types 或动态 DOM 变化时，游戏失败不影响网页基本功能。

## 11. 验证

自动化测试覆盖：

- 面积到耐久和基础分的映射。
- 单次伤害、击破奖励和连击倍率。
- 连击超时重置。
- 历史总分累加和剑解锁阈值。
- 组合键录制、规范化和默认值恢复。
- 损坏存储数据的安全回退。

手动验证覆盖：

- 在所有普通网页进入和退出模式。
- 自定义组合键生效且不干扰普通输入。
- 右键退出并恢复页面右键菜单。
- 点击不会误触链接和按钮。
- 小型、大型、嵌套及动态元素均可命中。
- 元素碎裂后退出模式或刷新可恢复。
- 同一页面刷分累加历史总分，换页后本页分数清零。
- 六把剑在达到阈值后解锁并可切换。
- 音效、静音、减弱动画和长时间运行稳定性。

## 12. 后续扩展

后续排行榜阶段在现有本地分数模型之上增加：

- 匿名用户自选名字。
- 每日全球最高分提交与查询。
- 服务端单日提交限制、频率限制和分数合理性校验。
- 排行榜 Provider 抽象，使本地模式与在线模式共用同一套界面。

排行榜不属于第一阶段验收范围。
