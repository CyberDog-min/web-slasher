# 手动测试指南

## 准备

1. 打开 Chrome 的 `chrome://extensions`。
2. 启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择仓库根目录。
4. 确认扩展卡片没有错误，再打开 `test/manual/fixture.html`。

测试时可以同时打开扩展弹窗观察分数变化。弹窗在关闭后不会保持页面脚本连接，重新打开会主动请求当前状态。

## 基础模式

1. 在测试页确认普通鼠标和页面点击工作正常。
2. 按 `Alt+Shift+S`，确认顶部模式状态、底部 HUD 和剑形光标出现。
3. 移动鼠标，确认剑形光标的方向跟随移动方向。
4. 单击左键，确认画面出现剑光和命中特效。
5. 单击右键，确认模式退出、系统指针恢复且右键菜单不弹出。

如果自定义了组合键，设置保存在 `chrome.storage.local` 的 `customCombo` 字段。重置按钮会恢复 `Alt+Shift+S`。

## 命中与耐久

依次测试以下项目：

| 页面目标 | 预期 |
| --- | --- |
| 小按钮 | 一击击破 |
| 中等卡片 | 两次击破 |
| 大型区域 | 三次或更多次击破 |
| 嵌套子按钮 | 优先命中子按钮，而不是外层容器 |
| 透明目标 | 不参与命中 |
| `visibility: hidden` 目标 | 不参与命中 |
| 3px 小目标 | 不参与命中 |
| 动态卡片 | 无需刷新即可命中 |
| 示例链接 | 点击不会触发跳转 |

一次斩击命中多个目标时，每个目标只结算一次伤害。连续点击间隔小于 90ms 时，后一次点击不会重复出剑。

## 分数与连击

1. 连续命中多个目标，确认 HUD 连击倍率逐步增长。
2. 等待超过约 1.5 秒再命中，确认倍率重置为 `x1.00`。
3. 记录弹窗中的历史总分，再刷新测试页。
4. 确认本页得分变为 0，历史总分不减少。
5. 累计达到 800、2,500、6,000、12,000、22,000 分时，确认对应剑解锁。
6. 切换不同剑，确认光标、剑光、火花和合成音色发生变化。

## 恢复

1. 进入模式并击破若干目标。
2. 退出模式，确认目标恢复原始尺寸、可见性和交互。
3. 再次进入模式并击破目标。
4. 刷新页面，确认页面重新加载后所有元素恢复。
5. 在测试页修改 hash 或查询参数，确认本页得分清零且已隐藏元素恢复。
6. 在模式内点击右键，确认系统指针、滚动、文本选择和页面右键菜单恢复正常。

扩展把原始 `style` 属性保存在内存中，不向网页写入持久数据。页面动态删除目标时，恢复步骤会安全跳过。

## 性能与兼容

1. 在三个不同的普通 `https` 网站测试模式切换和连续斩击。
2. 打开长页面并滚动到不同位置，确认剑刃坐标没有偏移。
3. 连续触发大量元素，确认粒子数量受到限制且页面仍可操作。
4. 在系统设置中启用“减少动态效果”，确认粒子与屏幕震动明显减少。
5. 打开 `chrome://extensions` 等禁止注入的页面，确认弹窗显示不支持提示且控制台没有未处理异常。

## 自动化检查

在仓库根目录运行：

```bash
npm test
```

测试覆盖面积分级、耐久、击破分、连击、剑解锁、组合键规范化和 DOM 命中辅助函数。页面渲染、Chrome Storage 和真实鼠标交互仍以本指南中的手动验收为准。

如果本机安装了 Chrome，还可以运行：

```bash
npm run smoke
```

该命令会启动临时 Chrome 配置和本地测试页，验证扩展加载、模式切换、元素隐藏与退出恢复。
