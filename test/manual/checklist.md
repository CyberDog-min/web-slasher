# 斩页手动验收清单

## 加载

- [ ] Chrome 打开 `chrome://extensions`，启用开发者模式。
- [ ] 选择“加载已解压的扩展程序”，目录指向仓库根目录。
- [ ] 扩展卡片没有 Manifest 或资源错误。
- [ ] 打开 `test/manual/fixture.html`，工具栏弹窗能读取当前页面状态。

## 模式切换

- [ ] 默认按 `Alt+Shift+S` 进入模式。
- [ ] 顶部状态、底部 HUD 和剑形光标出现。
- [ ] 再按一次组合键退出，完成后页面恢复普通指针。
- [ ] 模式中点击右键退出，并且页面右键菜单不弹出。
- [ ] 在设置页录制新组合键后，旧组合键失效，新组合键生效。
- [ ] 普通网页输入框不会在模式关闭时被组合键额外插入字符。

## 斩击与命中

- [ ] 单击会显示剑光，鼠标移动方向会影响斩击角度。
- [ ] 90ms 内连续点击不会重复结算同一次斩击。
- [ ] “小按钮”一次击破，并出现分数浮字。
- [ ] “中等卡片”需要两次击破。
- [ ] “大型区域”需要多次击破，击破分数明显更高。
- [ ] 剑刃经过嵌套区域时优先命中“嵌套子按钮”。
- [ ] 透明元素、`visibility: hidden` 元素和小于 4px 的元素不能被选中。
- [ ] 每两秒新增的动态卡片无需刷新即可斩击。
- [ ] 点击链接目标不会跳转到 `example.com`。
- [ ] 一次斩击轨迹经过多个目标时，可以同时命中多个目标。

## 分数与解锁

- [ ] 连续命中时 HUD 连击倍率增长，最高不超过 `x3.50`。
- [ ] 停止命中超过约 1.5 秒后，下一次命中从 `x1.00` 重新开始。
- [ ] 同一页面刷分后，弹窗中的历史总分持续累加。
- [ ] 刷新页面后本页得分归零，历史总分保留。
- [ ] URL 改变后本页得分归零，被斩击元素立即恢复。
- [ ] 达到 1,000、4,000、16,000、64,000、256,000 分后对应剑解锁。
- [ ] 锁定剑不能选择，解锁后选择会立即更换光标、剑光、火花和音色。

## 恢复与音效

- [ ] 击破元素后有缩淡、火花和碎屑反馈。
- [ ] 退出模式后所有被隐藏元素恢复原始布局与交互。
- [ ] 被斩击的链接、按钮和输入框不会保留扩展写入的不可见样式。
- [ ] 页面刷新后所有元素恢复。
- [ ] 弹窗关闭和重新打开后，本页分数、模式状态和音效状态显示正确。
- [ ] 关闭音效后不再播放斩击音色，重新开启后恢复。
- [ ] 系统启用“减少动态效果”时，动画和粒子数量明显下降。

## 稳定性

- [ ] 在三个普通 `https` 网站运行 10 分钟，无页面脚本报错。
- [ ] 长页面滚动后命中坐标仍然准确。
- [ ] 退出模式后页面滚动、点击、键盘输入和右键菜单均正常。
- [ ] `chrome://` 页面无法注入时，弹窗显示不支持提示且扩展不报错。
